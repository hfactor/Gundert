Script Declaration

The font declares languagesystem DFLT dflt; only — no mlym / mlm2. HarfBuzz activates the Malayalam shaper only when it sees those script tags in the GSUB ScriptList. Without them: default shaper runs — no reordering, no halant/virama logic, no conjuncts. All combinations come from explicit liga GSUB Type 4 rules.

languagesystem DFLT dflt;   /* no "languagesystem mlym dflt;" */
